# Planik 1.2

Планер для iPhone, що збирає докупи робочий графік, справи по дому, дні народження і звички. Працює як застосунок з іконкою на початковому екрані, без сервера. Усі дані зберігаються тільки на телефоні.

## Як встановити через GitHub Pages

1. Створи на GitHub новий публічний репозиторій, наприклад `planik`.
2. Розпакуй архів і завантаж **вміст** папки `planik` (не саму папку) у корінь репозиторію: *Add file → Upload files*. Мають бути видні `index.html`, `sw.js`, папки `css`, `js`, `fonts`, `icons`.
3. *Settings → Pages → Build and deployment → Source: Deploy from a branch*, гілка `main`, папка `/ (root)` → *Save*.
4. Через 1–2 хвилини сайт відкриється за адресою `https://<твій-логін>.github.io/planik/`.
5. На iPhone відкрий цю адресу **в Safari** → *Поділитися* → *На початковий екран* → *Додати*.
6. Запусти Planik з іконки і пройди знайомство.

## Як оновлювати

1. Заміни файли в репозиторії новими.
2. У `sw.js` зміни рядок `VERSION` (наприклад, `planik-v1.2.1`). Без цього телефон показуватиме стару версію з кешу.
3. Відкрий застосунок — зверху зʼявиться «Є нова версія Planik → Оновити».
4. Після оновлення Planik сам покаже сторіз «Що нового». Нову колоду для наступної версії додають у `js/whatsnew.js` (обʼєкт `DECKS`) і піднімають `VERSION` у `js/profile.js`.

## Що нового в 1.2

- **Нова палітра**: Tangerine `#F47742`, Cobalt `#2D4FC5`, Butter `#F4D58A` плюс чорний і білий. Темна тема перефарбована. Старі кольори категорій і трекерів переходять на нові автоматично.
- **Нова іконка**: календарик з усміхненим сонцем. Щоб вона зʼявилась на початковому екрані, видали Planik і додай знову через Safari. Дані лишаться.
- **Повтор за обраними днями тижня**: «Повтор → Обрані дні», далі кружечки Пн–Нд.
- **Настрій**: 8 намальованих настроїв. Зранку (5:00–12:00) і ввечері (з 18:00) питання під привітанням, минулі дні — тапом по дню в календарі. У Пульсі — картка «Настрій» з календарем місяця, частотою настроїв і спостереженнями. Настрій є в підсумкових сторіз.
- **Гроші** (нова вкладка): баланс, діаграма витрат і доходів, 25 категорій витрат і 8 доходів зі своїми іконками, свої категорії, ліміти, регулярні платежі (зʼявляються в календарі; відмітка «зроблено» записує витрату), скарбнички, порівняння з минулим місяцем, історія з пошуком, редагуванням і видаленням свайпом. Покупку, відмічену в Пульсі, Planik пропонує записати витратою. Гроші є в підсумкових сторіз.
- **Профіль** тепер відкривається тапом по аватарці на головному екрані.
- **Сторіз «Що нового»** після кожного оновлення. Повторно — Профіль → Що нового.

## Що вміє

- **Календар** у трьох виглядах (кнопка праворуч угорі):
  - **сітка місяця** з кольоровими мітками; натиск на день згортає місяць до тижня і показує план дня;
  - **стрічка днів**: картки-дні під закріпленою назвою місяця;
  - **таймлайн**.

  У стрічці й таймлайні наприкінці місяця зʼявляється кнопка «Наступний місяць».
- **Події, справи й дні народження**: категорії, повтори, особлива важливість, свої нагадування, місце, нотатки, список «що підготувати або купити». Подію можна змінити, видалити (з можливістю повернути) або експортувати в Календар iPhone.
- **Плашка «Важливо: скоро…»** на головному екрані для найближчої особливо важливої події.
- **Трекери** у дві колонки: «без звички» (рахує дні автоматично, є кнопка «Зрив») і «зі звичкою» (+/−). Трекер можна закріпити шпилькою, задати мету й кінцеву дату. Конструктор має живий перегляд і 42 іконки.
- **Пульс**: навантаження на 7 днів, протерміновані справи, дні народження на 2 місяці, загальний список покупок і слова підтримки.
- **Сповіщення**: центр сповіщень (дзвіночок) і лічильник на іконці.
- **Гроші**: див. «Що нового в 1.2».
- **Профіль** (тап по аватарці): імʼя, фото, нагадування за замовчуванням, свої категорії, резервна копія у Файли й відновлення з неї.

## Важливо про сповіщення

iPhone дозволяє вебзастосунку без сервера показувати сповіщення тільки тоді, коли Planik відкритий або щойно був відкритий. Лічильник на іконці оновлюється щоразу, коли ти заходиш у застосунок.

Щоб нагадування приходили навіть при закритому застосунку, у події є кнопка ⬇ «Додати в Календар iPhone». Вона створює подію в стандартному Календарі з тими самими нагадуваннями.

Повноцінні push-сповіщення потребують невеликого сервера (наприклад, безкоштовного Cloudflare Worker). Це можна додати наступним етапом.
